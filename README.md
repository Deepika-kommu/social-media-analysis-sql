# 📱 Social Media Analysis – SQL

## 📌 Project Overview

A SQL-based data analysis project designed to analyze social media user activity, engagement, content performance, and user behavior using relational database queries.

## 🛠️ Tools & Skills

* MySQL
* SQL
* Joins
* Subqueries
* CTEs
* Aggregate Functions
* GROUP BY
* HAVING
* CASE Statements
* Window Functions
* Data Analysis

## 📊 Analysis Performed

* Analyzed user activity and engagement
* Identified high-performing content
* Compared user engagement across different categories
* Analyzed user interaction patterns
* Calculated aggregate metrics using SQL
* Used advanced queries to derive business insights

## 🔎 SQL Concepts Used

* INNER JOIN
* LEFT JOIN
* GROUP BY
* HAVING
* CASE WHEN
* Subqueries
* Common Table Expressions (CTEs)
* ROW_NUMBER()
* RANK()
* DENSE_RANK()
* LAG()
* Aggregate and window functions

## 🎯 Project Objective

The objective of this project was to use SQL to transform raw social media data into meaningful insights that can support data-driven decision-making.
